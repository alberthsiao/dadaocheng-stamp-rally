# 璀璨煙火・時光拼圖 — 大稻埕永樂町逛街地圖

台北圓環太平永樂町商圈「璀璨煙火・時光拼圖」集章活動（115.7.25 – 8.14，70 家店）的**逛街助手**。

紙本 DM 適合蓋章，但走在路上要找店、算彩虹任務還差哪個顏色很不方便 — 這頁就是拿來邊走邊用的。

**純靜態、零依賴、零建置**：沒有 npm、沒有 build step，用瀏覽器打開 `index.html` 就能跑。

## 跑起來

```bash
# 方法一：直接開檔（功能都可用，但 file:// 下沒有離線快取，localStorage 也可能被擋）
open index.html

# 方法二：起個小 server（建議）
python3 -m http.server 8765
# → http://localhost:8765
```

## 功能

| 功能 | 說明 |
| --- | --- |
| 集章紀錄 | 點「蓋章」記下走過的店，存在瀏覽器 localStorage，重整不掉 |
| 彩虹任務進度 | 自動算完成幾次彩虹任務（七色各 1 家＝1 次，上限 3 次）與可夾扭蛋次數 |
| 七色進度條 | 每色已集幾家、三輪各自達成沒，點一下就當顏色篩選 |
| 搜尋 | 店名、地址、街道、顏色都能搜；輸入 1–2 位數字＝直接找該編號的店 |
| 篩選 | 顏色（可複選）× 未集章／已集章 × 街道 |
| 三種檢視 | 依顏色（對照 DM 版面）、**依街道**（同街道按門牌排序，就是走路順序）、依編號 |
| **規劃最短路線** | 定位後算出「最快完成下一次彩虹任務」的走法：七色各一家、順序最佳化，顯示每段距離與總步行時間 |
| **一鍵導航** | 把整條路線（起點＋7 站）送進 Google Maps 步行導航 |
| **依距離排序** | 定位後每張卡片顯示距離，可依遠近排序 |
| **街道地圖** | 內嵌向量地圖（OpenStreetMap 圖資），標出 70 家店、已集章狀態、你的位置與規劃出的路線；點地圖上的店直接跳到卡片。**完全離線可繪**，不載入任何外部圖磚 |
| 地圖 | 每家店一鍵開 Google Maps；另有主辦單位的官方地圖與活動影片連結 |
| 筆記 | 每家店可寫備註（吃了什麼、營業時間） |
| 備份／還原 | 匯出成 JSON，換手機或清快取前先存一份 |
| 活動規則 | DM 背面 9 條規則**原文照錄**，放在頁面上方、預設展開；收合狀態會記住 |
| 定位求助 | 定位被拒絕時跳出重新開啟權限的步驟（iPhone／Android／已加到主畫面三種情況），並說明不定位也能用 |
| 亮／暗色 | 預設跟隨系統；白天在街上建議切亮色 |
| 離線可用 | Service Worker 快取全站，騎樓、市場裡沒訊號也打得開 |
| 加到主畫面 | PWA，手機「加入主畫面」後像 app 一樣全螢幕開啟 |

集章紀錄只存在自己的裝置，沒有後端、不上傳任何東西。

### 加到主畫面

需要透過 http(s) 開啟（`file://` 不支援 Service Worker）：

- **iOS Safari**：分享 → 加入主畫面
- **Android Chrome**：右上選單 → 安裝應用程式／加到主畫面

裝好後首次開啟會把頁面與圖示快取起來，之後沒網路也能查店家、蓋章、看路線。

## 部署

整包丟上任何靜態空間即可，不需後端：

- **Cloudflare Pages／Netlify／Vercel**：連 repo 後，build command 留空、輸出目錄設為專案根目錄。**private repo 也支援**，部署出來的網址是公開的，可以直接分享給朋友一起集章。
- **GitHub Pages**：Settings → Pages → Source 選 `Deploy from a branch`，branch `main`、資料夾 `/ (root)`。⚠️ 免費方案的 **private repo 不能用 Pages**，需把 repo 轉為 public 或升級付費方案。
- **自己的機器**：任何能服務靜態檔的 web server 都行（nginx、Caddy、`python3 -m http.server`）。

部署後記得用 **https**（或 localhost），Service Worker 才會生效。

## 檔案

```
.
├── index.html      頁面結構
├── styles.css      夜空×燙金主題（亮色模式用 [data-theme="light"] 覆寫變數）
├── data.js         70 家店家資料 + 七色定義 + 活動資訊與規則
├── app.js          篩選／分組／集章／彩虹任務計算／備份
├── mapdata.js      大稻埕街道向量圖資（OSM，17 KB）
├── manifest.json   PWA 設定
├── sw.js           Service Worker（stale-while-revalidate）
└── icons/          app 圖示（192／512／maskable／apple-touch）
```

改店家資料只要動 `data.js` 的 `SHOPS`；每筆的 `street` 與 `no`（門牌主號）是「依街道」檢視的排序依據，`lat`/`lon` 供距離與路線計算。官方連結集中在 `EVENT.links`。

### 座標從哪來

70 家店的座標取自 **OpenStreetMap 的門牌點**（Overpass API），其中 68 家對到實際門牌；歸綏街 238 號與迪化街一段 224 巷 24 號在 OSM 沒有對應門牌，改由同一側相鄰門牌線性內插（標記 `approx: true`，誤差約 10 公尺內）。交叉驗證：永樂市場的 OSM 座標與 Nominatim 獨立查詢相距 13 公尺。

### 地圖怎麼來

沒有嵌 Google Maps 或 Leaflet ——那會破壞「零依賴、離線可用」這兩件事。改用 Overpass API 抓大稻埕的街道幾何（315 條路、1524 個節點），轉成以公尺為單位的座標存進 `mapdata.js`（17 KB），前端直接畫成 SVG。整張圖在飛航模式下也畫得出來。

街道分三個等級疊圖，13 條主要街道有名稱標籤（直排用逐字 `tspan`，SVG 的 `writing-mode` 在多數瀏覽器不會正確斷行）。同一座標的店家會繞圈散開 —— 永樂市場一棟樓裡就有黃綠藍靛四家。

### 路線怎麼算

「最快完成彩虹任務」不是單純挑各色最近的一家 —— 起步最近的店可能讓後面繞遠路。作法是每色取離起點最近的 3 家當候選，列舉 3⁷ = 2187 種組合，每組再用 2-opt 最佳化順序，取總步行距離最短者。實測在三個不同起點都與窮舉最佳解一致，耗時約 100 毫秒。

改版部署後若手機還看到舊畫面，把 `sw.js` 裡 `CACHE` 的版本號 +1 即可，舊快取會在下次啟用時清掉。

## 注意

- 資料整理自活動 DM（已逐筆核對 70 家的編號、店名、地址與顏色分組），**活動規則與店家資訊以主辦單位公告為準**；本站為非官方輔助工具。
- 站內的「蓋章」只是自己的行程紀錄，**不等於官方印章、也不能兌換扭蛋或摸彩** — 實體印章仍須到店消費後由店家蓋在紙本 DM 上相同編號的格子裡，編號不符視為無效。首頁進度區有常駐提醒說明這件事。
